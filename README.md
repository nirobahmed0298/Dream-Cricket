# Dream 11 Cricket Team
**Name of my project** : Dream 11 Cricket Team

**A brief description** : Dream Squad 11 is a cricket fan's paradise where users can assemble their ultimate "Dream 11" cricket team. Select from a range of legendary and current players across all formats to create a personalized squad. Compete with friends, explore top picks, and see how your dream team stacks up against others in the community.

**Technologies used** : 
- JSX
* Components
+ Hooks

**3 key features of your project** : 
- Claim Free Credite button is clicked, the user's currency will increase so that the user can buy players.
* Choose player on click, will show a warning to the user if the player is already selected (player already selected).
+ Clicking a "Remove" button on each selected player card will delete the player from the selected player category.
